========================================================================
INSTRUCCIONES PARA INTEGRAR GOOGLE FONTS (Fredoka, Poppins, Rajdhani)
========================================================================

Opción 1: Downloadable Fonts (Configurado en app/src/main/res/font/)
---------------------------------------------------------------------
El proyecto incluye definiciones XML para descargar automáticamente las fuentes desde Google Fonts:
- @font/fredoka (Fredoka - Ideal para títulos lúdicos)
- @font/poppins (Poppins - Ideal para textos legibles)
- @font/rajdhani (Rajdhani - Perfecto para detalles científicos)

Opción 2: Archivos TTF locales
------------------------------
1. Descargar las familias desde Google Fonts (https://fonts.google.com/).
2. Copiar los archivos .ttf dentro de 'app/src/main/res/font/':
   - fredoka.ttf
   - poppins.ttf
   - rajdhani.ttf
3. Todos los nombres deben estar en minúsculas.
